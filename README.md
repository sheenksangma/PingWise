🚀 Features

🔒 Secure Authentication using JWT and cookie-based sessions
💬 Real-Time Messaging via WebSockets (Socket.IO)
📎 Image Sharing Support with previews in chat
📱 Responsive UI designed for desktop and mobile browsers
📊 Enterprise-grade Scalability supporting concurrent users
👤 Profile Management: Update display names and profile pictures

-----------------------------------------------------------------

🏗️ Tech Stack

Frontend- React.js, Tailwind CSS, Vite
Backend- Node.js, Express.js
Real-Time- Socket.IO
Database- MongoDB Atlas (Cloud-hosted)
Media Storage- Cloudinary
Deployment- Render (for backend + frontend)
Version Control- Git, GitHub

-----------------------------------------------------------------

🛠️ Setup & Installation

📦 Prerequisites
Node.js v20+
npm
MongoDB Atlas account (or your own DB URI)
Cloudinary account for media uploads

-----------------------------------------------------------------

🔥 Local Development

Clone the repository
git clone https://github.com/sheenksangma/PingWise.git
cd PingWise
Install dependencies
npm install --prefix backend
npm install --prefix frontend
Setup environment variables
Copy .env.example to .env inside backend/
Add MongoDB Atlas URI and Cloudinary credentials
Run the backend
npm run start --prefix backend
Run the frontend
npm run dev --prefix frontend
Open the app in browser at http://localhost:5173
